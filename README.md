# Brazilian E-Commerce Data Cleaning — Olist

## Overview
A Python and Pandas project focused on data quality assessment and cleaning of the Brazilian E-Commerce Public Dataset by Olist.

## Objectives
- Inspect missing values and duplicate records.
- Investigate missing delivery dates.
- Convert date columns to datetime.
- Prepare datasets for SQL analysis and Power BI.

## Technologies
- Python
- Pandas
- CSV
- Git and GitHub

## Dataset
Kaggle: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Setup
Install dependencies:

    pip install -r requirements.txt

Run the script:

    python main.py

## Project Status
In progress. Future work includes validating relationships between customers, orders, payments, and products, and standardizing product categories.
